# Mixed Delivery Invoice Tracker

Foundation First tool for tracking monthly Mixed Delivery invoices by program: slots by age group, rates, prorated copays, advances, repayments, payments and month-end reconciliation against Bill.com.

**Open the tracker:** https://mowcky.github.io/md-invoice-tracker/

## How data is saved
- No payment data is stored in this repository. Entries are saved in the browser you use.
- Use **Back up** (top right) after each month's entries and keep the backup file on SharePoint.
- Use **Restore** to load a backup into another browser or computer.
- Do not upload backup (.json) files or exports to this repository; it is public.

## Updating
Replace `index.html` with the new version. Saved data in your browser is not affected.
